1. The Problem & Motivation

Autonomous AI coding agents (Claude Code, OpenAI Codex) execute broad shell commands, install system libraries, and compile software. Running these agents directly on developer workstations poses severe security risks: exposing personal documents, SSH keys, and browser cookies.

"Bring Your Own Agent. We Bring the Box."
Decouple agent intelligence from host operating environments.

Core Research Questions

  • RQ1 (Graphical Concurrency): Can a single container multiplex discrete X11 desktop sessions without cursor contention?
  • RQ2 (Multi-User POSIX Integrity): How can Google Drive-style sharing map onto Linux UIDs and Git attribution without credential leakage?
  • RQ3 (Latency & Efficiency): What are the latency overheads of in-browser RFB-over-WebSocket multiplexing?

2. System Architecture

DreamBees reconstructs the classic multi-user time-sharing computer inside lightweight Ubuntu 24.04 containers:

  • Control Plane (Node.js/TS): Deterministic 10-state lifecycle engine, job ledger, and second-by-second cost accounting.
  • Display Gateway (Port 3030): Bridges binary RFB protocol frames across WebSockets directly to an in-browser HTML5 canvas (noVNC).
  • Multi-User Multiplexing: Owner connects to DISPLAY :0 (Port 5900); invited collaborators trigger dynamic on-demand spawns of DISPLAY :1..N (Port 5901+).

3. Multiplayer & Security Topology

DreamBees rejects screen sharing. Collaborators receive dedicated graphical desktop viewports while sharing a single persistent project workspace:

  • Private Home Dirs (/home/<user>): Permissions drwx------ (0700). Claude Code tokens (~/.claude.json) and Codex credentials remain strictly isolated.
  • Shared Workspace (/home/operator/workspace): Permissions 2775 with setgid bit active under group agentbox. All files created by any collaborator are group-writable.
  • Git Author Attribution: Commits automatically resolve user identity from private ~/.gitconfig, preserving authentic human accountability.

Remediated Adversarial Failure Modes

  • Symlink Escape Defense: Naïve tar exports followed symlinks to /etc/shadow. Replaced with Python realpath validation; escapes filtered.
  • Scoped Git Trust: Replaced vulnerable safe.directory "*" with scoped paths (/home/operator/workspace).
  • Instant Revocation: Active WebSockets tracked synchronously; revocation terminates live TCP streams in 12.1 ms.

5. Economic Model & Commercial Post-Mortem

DreamBees enforces transparent, itemized infrastructure accounting:

  • Active Compute: $0.05 / $0.10 / $0.20 per hour (Standard, Power, Titan).
  • Paused Compute: $0.00/hr active compute + $0.01/hr reserved infrastructure + $0.10/GiB-month persistent NVMe storage.
Why Commercial Hosting Was Declined:
Reselling commodity compute yields <15% gross margin while bearing 100% of customer support for stateful Linux desktop corruption.

6. Limitations & Scientific Disclosures

  • BLOCKED Human Usability Study: 5-person usability trial unperformed. No human completion rates or satisfaction scores fabricated.
  • Local vs. WAN Latency: 12ms RFB latency reflects local loopback; wide-area network latency governed by RTT.
  • Intentional Shared Execution: Collaborators share workspace write access; code executed by peers runs with local permissions.

7. Conclusions & Archival Preservation

DreamBeesAI demonstrates that classical multi-user time-sharing principles provide a secure, accessible substrate for autonomous AI agents. The software is officially frozen and published under the Apache License, Version 2.0.
