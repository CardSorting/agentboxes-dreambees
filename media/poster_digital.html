1. Research Motivation

Autonomous AI agents (Claude Code, OpenAI Codex) execute broad shell commands. Running agents locally introduces severe workstation risks: exposing personal files, private keys, and browser cookies.

"Bring Your Own Agent. We Bring the Box."
Isolates agent execution inside a pre-baked cloud desktop without local setup.

2. Architecture Topology

  • Control Plane: 10-state lifecycle engine, job ledger runner, and real-time cost accounting.
  • Display Gateway: Direct RFB-over-WebSocket bridge connecting container X11 sockets to noVNC in browser.
  • Container Workstation: Ubuntu 24.04 with XFCE, Claude Code, Codex, Chrome, Node 22, Git.

3. Independent Multiplayer

Rejects screen-sharing in favor of independent virtual displays multiplexed through a single container:

  • Owner Desktop (DISPLAY :0): Connects via port 5900 under user operator (UID 1000).
  • Collaborator Desktop (DISPLAY :1): On-demand Xvfb/x11vnc session on port 5901 under user collab_1 (UID 1001).
  • Home Directory Isolation: Mode 0700 strictly isolates Anthropic/OpenAI credentials.
  • Shared Workspace: Mode 2775 / setgid at /home/operator/workspace enables joint code compilation.
  • Git Attribution: Individual author identity preserved from private ~/.gitconfig.

5. Failure Analysis

  • Symlink Escape Filter: Python realpath validation prevents /etc/shadow tar leaks.
  • Scoped Git Trust: Replaced wildcard * with scoped workspace path.
  • Subnet Self-Healing: Prunes dangling networks on Docker pool exhaustion.

6. Scientific Disclosures

  • BLOCKED Human Usability Study: 5-person clinical trial unperformed. No human satisfaction scores fabricated.
  • Localhost vs WAN: 12ms RFB latency measured on local interconnect. WAN latency governed by RTT.
  • Shared Workspace Trust: Collaborators intentionally share write access to execute code together.

7. Archival Conclusion

Proves that classical Unix time-sharing and in-browser RFB provide a robust host for autonomous agents. Published open source under Apache 2.0.
