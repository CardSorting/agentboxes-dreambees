## 2. Experimental Honesty & Verification Disclosures

1. **Automated Testing vs. Human Subjects:** All reported performance, latency, concurrency, and security benchmarks were obtained using automated integration test harnesses against live Linux containers. A planned five-person human usability study was not conducted due to the absence of human cohorts and is formally reported as **BLOCKED**. No human usability data has been fabricated.
2. **Third-Party Model Invocations:** Agent execution tests verified that `@anthropic-ai/claude-code` and `@openai/codex` CLIs install correctly, spawn desktop terminals, and parse authentication files. Live model reasoning over the internet requires an active customer API key or OAuth subscription; offline test harnesses utilized simulated test keys.
3. **Local Loopback Latency:** All reported RFB connection and frame transfer latencies were measured over localhost interconnects. Real-world internet latency will vary based on user network conditions and distance from host infrastructure.
4. **Economic Accounting:** Operating costs for compute ($0.05/$0.10/$0.20 per hour) and persistent storage ($0.10/GiB-month) are based on standard bare-metal server amortization. No commercial billing was activated for external customers.
